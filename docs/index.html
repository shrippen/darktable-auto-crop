Auto Crop
Negative

A Darktable plugin that crops camera scans of film negatives to the analog film frame. Uncertain detections get a red color label for manual review.

Ein Darktable-Plugin, das digitalisierte Filmnegative automatisch auf den analogen Filmrahmen zuschneidet. Unsichere Erkennungen bekommen ein rotes Farblabel zur Kontrolle.

git clone https://github.com/shrippen/darktable-auto-crop.git && cd darktable-auto-crop && chmod +x install.sh && ./install.sh

Requires Darktable 4.0+ with Lua, Python 3.8+, OpenCV and NumPy. Restart Darktable afterwards.

Benötigt Darktable 4.0+ mit Lua, Python 3.8+, OpenCV und NumPy. Danach Darktable neu starten.

DetectionErkennung

Finds the film frame

Findet den Filmrahmen

When you digitize negatives with a camera, the film strip and table stay in the picture. The plugin detects the frame and crops it exactly.

Beim Abfotografieren von Negativen bleiben Filmstreifen und Tisch im Bild. Das Plugin erkennt den Rahmen und schneidet ihn passgenau zu.

StrategiesStrategien

Four detection strategies

Vier Erkennungsstrategien

Contour analysis, Canny + Hough, gradient transitions and a brightness mask run in parallel. Agreement between them boosts confidence.

Konturenanalyse, Canny + Hough, Gradienten-Übergänge und eine Helligkeitsmaske laufen parallel. Übereinstimmungen erhöhen die Konfidenz.

ConfidenceKonfidenz

Confidence scoring

Konfidenz-Bewertung

A value from 0.0 to 1.0 per candidate, based on aspect ratio, area, border distance, edge contrast and strategy agreement.

Ein Wert von 0,0 bis 1,0 pro Kandidat, berechnet aus Seitenverhältnis, Fläche, Randabstand, Rand-Kontrast und Strategie-Übereinstimmung.

ReviewKontrolle

Color labels for review

Farblabels zur Kontrolle

Below the threshold (default 0.7) the crop is still applied, but the image gets a red label. At or above it the image gets a green label.

Unter der Schwelle (Standard 0,7) wird trotzdem zugeschnitten, das Bild bekommt aber ein rotes Label. Ab der Schwelle bekommt es ein grünes Label.

FormatsFormate

Film formats

Filmformate

35 mm (135) by default, plus medium format 6×6, 6×4.5, 6×7 and 6×9.

Standardmäßig Kleinbild (135), dazu Mittelformat 6×6, 6×4,5, 6×7 und 6×9.

BatchStapel

Lua frontend, Python backend

Lua-Frontend, Python-Backend

Crop one image or all selected images from the darkroom. Darktable talks to an OpenCV and NumPy backend via JSON.

Ein Bild oder alle ausgewählten Bilder direkt aus der Dunkelkammer zuschneiden. Darktable spricht per JSON mit einem OpenCV- und NumPy-Backend.

Usage

Nutzung

  1. Open an image in the darkroom and click Crop single image. The plugin appears as the panel “Auto Crop Negative” in the right sidebar.
  2. For several images, select them in the lighttable, then click Crop all selected in the darkroom.
  3. Check the result: red label means review needed, green label means OK.
  1. Öffne ein Bild in der Dunkelkammer und klicke auf Einzelbild zuschneiden. Das Plugin erscheint als Panel „Auto Crop Negative“ in der rechten Seitenleiste.
  2. Für mehrere Bilder wählst du sie in der Leuchttisch-Ansicht aus und klickst in der Dunkelkammer auf Alle ausgewählten zuschneiden.
  3. Prüfe das Ergebnis: rotes Label bedeutet Kontrolle nötig, grünes Label bedeutet in Ordnung.

Installation

Installation

The install script copies the Lua and Python files into ~/.config/darktable/lua/. Manually:

Das Installationsskript kopiert die Lua- und Python-Dateien nach ~/.config/darktable/lua/. Manuell:

  1. Copy auto_crop_negative.lua and auto_crop_negative.py to ~/.config/darktable/lua/ and make the script executable.
  2. Add require "auto_crop_negative" to ~/.config/darktable/lua/init.lua, or create the file with that line.
  1. Kopiere auto_crop_negative.lua und auto_crop_negative.py nach ~/.config/darktable/lua/ und mache das Skript ausführbar.
  2. Ergänze require "auto_crop_negative" in ~/.config/darktable/lua/init.lua oder lege die Datei mit dieser Zeile an.

Test ohne Darktable:
