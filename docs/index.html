Auto Crop
Negative

A Darktable plugin that crops camera scans of film negatives to the analog film frame. Every result gets a green, yellow or red label, so you know which ones to check.

Ein Darktable-Plugin, das digitalisierte Filmnegative automatisch auf den analogen Filmrahmen zuschneidet. Jedes Ergebnis bekommt ein grünes, gelbes oder rotes Label, damit du weißt, welche du prüfen musst.

git clone https://github.com/shrippen/darktable-auto-crop.git && cd darktable-auto-crop && chmod +x install.sh && ./install.sh

Requires Darktable 4.0+ with Lua, Python 3.8+, OpenCV and NumPy. Restart Darktable and enable it in the Script Manager.

Benötigt Darktable 4.0+ mit Lua, Python 3.8+, OpenCV und NumPy. Danach Darktable neu starten und im Script Manager aktivieren.

DetectionErkennung

Finds the film frame

Findet den Filmrahmen

When you digitize negatives with a camera, the film strip and table stay in the picture. The plugin detects the frame and crops it exactly.

Beim Abfotografieren von Negativen bleiben Filmstreifen und Tisch im Bild. Das Plugin erkennt den Rahmen und schneidet ihn passgenau zu.

RollRolle

Roll consensus

Konsens pro Rolle

One folder counts as one roll. The crop size is fixed to the robust median over the roll, and each image only has to find its position.

Ein Ordner zählt als eine Rolle. Die Crop-Größe wird auf den robusten Median der Rolle festgelegt, und jedes Bild muss nur noch seine Position finden.

ConfidenceKonfidenz

Confidence score

Konfidenz-Wert

Every result gets a value from 0.0 to 1.0. It combines size agreement with the roll, edge score and roll trust, and is capped for under-exposed images.

Jedes Ergebnis bekommt einen Wert von 0,0 bis 1,0. Er verbindet Größenübereinstimmung mit der Rolle, Kanten-Score und Vertrauen in die Rolle und ist bei unterbelichteten Bildern gedeckelt.

LabelsLabels

Green, yellow, red

Grün, Gelb, Rot

Green (0.5 and up): cropped. Yellow (0.3 and up): cropped, please check. Below that: not cropped, red label.

Grün (ab 0,5): zugeschnitten. Gelb (ab 0,3): zugeschnitten, bitte prüfen. Darunter: nicht zugeschnitten, rotes Label.

UndoRückgängig

Non-destructive

Nicht destruktiv

The crop is applied as a Darktable style. Two undo buttons switch the crop module off again, for the selected images or for the whole session, as a new history step.

Der Zuschnitt wird als Darktable-Style angewendet. Zwei Rückgängig-Knöpfe schalten das Crop-Modul wieder ab, für die ausgewählten Bilder oder für die ganze Sitzung, als neuer Verlaufsschritt.

Sieh, was die Erkennung gefunden hat

Prüfe die gelben, spare dir den Rest

Nach einem Lauf zeigt die Leuchttisch-Ansicht das Ergebnis als Farblabels. Grüne Zuschnitte sind angewendet und können bleiben. Gelbe sind ebenfalls angewendet, verdienen aber einen Blick. Rote Bilder bleiben unbeschnitten, es wird also nichts geraten.

How it works

So funktioniert es

A Lua frontend inside Darktable hands the images to a Python backend and takes the crop back as JSON. The backend does the image analysis with OpenCV and NumPy.

Ein Lua-Frontend in Darktable übergibt die Bilder an ein Python-Backend und nimmt den Zuschnitt als JSON zurück. Das Backend erledigt die Bildanalyse mit OpenCV und NumPy.

Usage

Nutzung

  1. Enable the plugin: Lua → Script Manager → contrib → Auto Crop Negative.
  2. In the lighttable, select the images of one roll and click Detect & Queue.
  3. Wait for the run. The status line shows progress and remaining time, and the color labels appear.
  4. Open the images in the darkroom to apply the crops, or click Apply all queued now.
  5. Check the yellow images. Undo a crop with Undo crop and fix it by hand if needed.
  1. Aktiviere das Plugin: Lua → Script Manager → contrib → Auto Crop Negative.
  2. Wähle im Leuchttisch die Bilder einer Rolle aus und klicke auf Detect & Queue.
  3. Warte auf den Lauf. Die Statuszeile zeigt Fortschritt und Restzeit, und die Farblabels erscheinen.
  4. Öffne die Bilder in der Dunkelkammer, um die Zuschnitte anzuwenden, oder klicke auf Apply all queued now.
  5. Prüfe die gelben Bilder. Nimm einen Zuschnitt mit Undo crop zurück und korrigiere ihn bei Bedarf von Hand.

Keyboard shortcuts can be assigned under Preferences → Keyboard → Auto Crop Negative.

Tastenkürzel lassen sich unter Voreinstellungen → Tastatur → Auto Crop Negative zuweisen.

Where it stands

Wo es steht

The Darktable side works: detection, queue, applying the crop and undo. The hard part is the detection itself. The hit rate is not good enough yet, and the confidence is not reliable: some results marked green were clearly wrong.

Die Darktable-Seite funktioniert: Erkennung, Warteschlange, Zuschnitt anwenden und Rückgängig. Schwierig ist die Erkennung selbst. Die Trefferrate ist noch nicht gut genug, und die Konfidenz ist nicht verlässlich: Manche grün markierten Ergebnisse waren deutlich falsch.

The reason is that the confidence mostly measures whether a roll agrees with itself, not whether the crop matches the real frame. If the detection makes the same mistake on a whole roll, it looks very sure.

Der Grund: Die Konfidenz misst vor allem, ob eine Rolle mit sich selbst übereinstimmt, nicht ob der Zuschnitt zum echten Bild passt. Macht die Erkennung auf einer ganzen Rolle denselben Fehler, wirkt sie sehr sicher.

Review tool

Kontroll-Werkzeug

For the calibration, a small review GUI lets you go through detection results, mark them OK or problem, and drag the crop corners to the right place. The corrected crops become the reference data.

Für die Kalibrierung lässt du in einer kleinen Review-Oberfläche die Erkennungsergebnisse durchgehen, markierst sie als OK oder Problem und ziehst die Crop-Ecken an die richtige Stelle. Die korrigierten Crops werden zu den Referenzdaten.

  • Start it with start_review_gui.sh
  • Arrow keys navigate, O marks OK, P marks a problem, R resets, Ctrl+S saves

Questions

Fragen

Can I trust a green label?Kann ich einem grünen Label trauen?

Not blindly. Green means the result agrees with the rest of the roll, not that it is proven right. Look at a sample of the green images too, until the detection has improved.

Nicht blind. Grün heißt, das Ergebnis passt zum Rest der Rolle, nicht dass es erwiesen richtig ist. Sieh dir auch von den grünen Bildern eine Stichprobe an, bis sich die Erkennung verbessert hat.

Why are red images not cropped?Warum werden rote Bilder nicht zugeschnitten?

A wrong crop costs more than no crop. Below the yellow threshold the plugin leaves the image alone and only labels it, so you decide.

Ein falscher Zuschnitt kostet mehr als kein Zuschnitt. Unter der Gelb-Schwelle lässt das Plugin das Bild in Ruhe und markiert es nur, du entscheidest also.

Does it change my original files?Ändert es meine Originaldateien?

No. The crop is a normal Darktable history step, and the undo buttons turn it off again. The scans are not touched.

Nein. Der Zuschnitt ist ein normaler Darktable-Verlaufsschritt, und die Rückgängig-Knöpfe schalten ihn wieder ab. Die Scans werden nicht angefasst.

Why one roll at a time?Warum eine Rolle nach der anderen?

The plugin assumes a folder is one roll, shot with the same camera and distance, so the frame size is almost constant. It uses the median size over the roll and only solves the position per image.

Das Plugin nimmt an, dass ein Ordner eine Rolle ist, mit gleicher Kamera und gleichem Abstand fotografiert, sodass die Rahmengröße fast konstant ist. Es nutzt die Median-Größe der Rolle und löst pro Bild nur die Position.
